# Lib > Features > Inventory

## Overview
Warehouse inventory management, chemical container tracking, fixed asset maintenance, and storekeeper shift handovers.

## Subdirectories & Boundaries
- [data](./data/README.md): Data layer managing inventory seed records and stock persistence.
- [domain](./domain/README.md): Domain models and transaction entities for warehouse tracking and chemical yield auditing.
- [presentation](./presentation/README.md): User interface presentation layer for warehouse storekeepers.
