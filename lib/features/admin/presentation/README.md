# Lib > Features > Admin > Presentation

## Overview
User interface presentation layer for station administrative control and management oversight.

## Subdirectories & Boundaries
- [screens](./screens/README.md): Administrative screens for executive dashboards, accountant reconciliations, commission logs, credential management, pricing matrix, and staff rosters.
- [widgets](./widgets/README.md): Specialized administrative UI widgets including revenue KPI cards, pricing matrix editors, audit log tiles, and AI executive sheets.
