# Lib > Features > Cashier > Presentation

## Overview
User interface presentation layer for cashier gate operations and payment workflows.

## Subdirectories & Boundaries
- [screens](./screens/README.md): Cashier desk screens for dashboard monitoring, walk-in check-in, bay assignment modals, payment processing, bank deposits, and daily shift closings.
- [widgets](./widgets/README.md): Cashier UI components for active queue tiles, live bay status cards, station money tabs, and intake forms.
