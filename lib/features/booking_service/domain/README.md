# Lib > Features > Booking_Service > Domain

## Overview
Enterprise business entities, aggregates, and repository contracts for car wash operations.

## Subdirectories & Boundaries
- [models](./models/README.md): Core domain models for bay stations, car types, payment information, service packages, wash bookings, and lifecycle statuses.
- [repositories](./repositories/README.md): Abstract repository contract defining database operations for wash bookings, receipts, and staff commissions.
