# Lib > Features > Customer > Presentation

## Overview
User interface presentation layer for customer reservations and wash tracking.

## Subdirectories & Boundaries
- [screens](./screens/README.md): Customer views for capacity monitoring, multi-step booking wizard, live visual progress stepper, and past booking receipts.
- [widgets](./widgets/README.md): Customer UI widgets including vehicle category selectors, live progress steppers, negotiable price chips, and station availability cards.
