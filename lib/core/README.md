# Lib > Core

## Overview
Shared foundational infrastructure providing design tokens, trilingual localization, asynchronous integrations, utility helpers, and base UI widgets.

## Subdirectories & Boundaries
- [constants](./constants/README.md): App-wide design tokens, Bishoftu aquatic color palettes, business configuration constants, and Material 3 theme styling.
- [localization](./localization/README.md): Trilingual localization engine providing complete UI translations across English (EN), Afaan Oromoo (OM), and Amharic (AM).
- [services](./services/README.md): Shared background and asynchronous services for AI executive assistance and bank receipt image OCR scanning.
- [utils](./utils/README.md): Utility helpers for currency formatting, date manipulation, image compression, asset paths, and audio/haptic feedback.
- [widgets](./widgets/README.md): Universal reusable UI components including buttons, text fields, glass containers, circular progress rings, video players, and header controls.
